# 函数域 · Function Domain

用公式把曲线引向光点的函数图像解谜游戏。30 个关卡，10 种函数形态，支持中英双语与禁区约束。

![version](https://img.shields.io/badge/version-1.0.1-7bf1c4)

## 直接开玩

下载仓库里的 **`函数域-V1.0.1.html`**，双击即可运行——CSS 与 JS 全部内联，不依赖服务器，也不需要任何第三方库。

开发时也可以直接打开 `index.html`（读取同目录的 `style.css` / `game.js`）。

## 玩法

| 操作 | 说明 |
|---|---|
| ▲ / ▼ | 参数每秒 ±1 匀速变化，再点一次暂停 |
| 输入框 | 直接键入数值，或用 ▲▼ 启动自动增减 |
| 停止 | 每个参数的「停止」键让数值定格；顶部「全部停止」一次停掉所有参数 |
| 粘贴 | 在任意参数框粘贴整条公式（如 `y = 2x + 1`、`y = -|x - 1| + 2`）自动填参 |
| 提示 | 顶部「提示」按钮显示当前关卡的思路 |
| 官方解法 | 设置区「官方解法」可展开，支持一键套用对照 |

曲线经过所有光点并保持 0.26 秒即通关。若曲线扫过目标点或与「目标图像」重合，自动增减会立刻停住。

后期关卡会出现**禁区**（矩形 / 圆形 / 整个象限），曲线任何一段进入禁区都无法通关。

## 关卡与函数

| 阶段 | 关卡 | 主要内容 |
|---|---|---|
| 基础 | 1–4 | 一次函数、绝对值 |
| 二次 | 5–9 | 抛物线、多点约束、禁区 |
| 反比例 | 10–14 | 双支曲线、偏移、多禁区 |
| 正弦 | 15–19 | 振幅/频率/偏移、密集波形 |
| 指数 | 20–23 | 快速上升、阶梯点位 |
| 复合 | 24–27 | 根式、整流正弦、三次、平方反比 |
| 综合 | 28–30 | 多公式组合、多禁区 |

函数按通关进度解锁：一次/绝对值初始可用，二次（4 关）、反比例（9 关）、正弦（14 关）、指数（19 关）、根式（23 关）、整流正弦（24 关）、三次（25 关）、平方反比（26 关）。

## 目录结构

```
function-domain/
├── index.html              页面骨架与静态文案（带 data-i18n）
├── style.css               全部样式（含中英文排版、动效）
├── game.js                 逻辑：函数族 / 关卡数据 / i18n / 渲染 / 交互 / 存档
├── 函数域-V1.0.1.html      构建产物：可直接双击的单文件版
├── build-standalone.mjs    生成单文件版（--check 校验产物是否最新）
├── check-data.mjs          数据自检（关卡/解法/英文名/i18n 键一致性）
└── publish-gh.mjs          同步到 GitHub 发布目录并推送
```

版本号只有一个来源：`game.js` 里的 `const VERSION`。页面展示、单文件命名、发布说明都读它。

## 开发命令

```bash
node build-standalone.mjs          # 生成 函数域-V1.0.1.html
node build-standalone.mjs --check  # 校验产物是否与源码一致
node check-data.mjs                # 数据与文案自检
node publish-gh.mjs                # 构建 + 同步 + 提交 + 推送到 GitHub
```

`publish-gh.mjs` 的目标目录可用参数或环境变量 `FD_PUBLISH_DIR` 覆盖，git 可执行文件可用 `GIT_EXE` 指定。
